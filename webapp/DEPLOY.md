# Deploying your Content Agent Dashboard Tool

This is a small Next.js app: a password-gated form where you enter your
Instagram handle + competitors + a few details, it pulls real data via
Apify, runs a rule-based (no AI) analysis, and generates the same
6-tab dashboard we built by hand earlier — automatically.

It was built and tested locally in a sandboxed environment that blocks
outbound calls to api.apify.com, so the live Apify integration could only
be verified up to the point of the network call failing with a clear
"host not in allowlist" error — that error is specific to that sandbox.
Vercel's servers have normal internet access, so this should work once
deployed; **the first real run on Vercel is the true end-to-end test.**
If anything breaks there, send me the error and I'll fix it.

## 1. Get the code onto GitHub

1. Create a new empty repository on [github.com](https://github.com/new) —
   call it whatever you like (e.g. `content-agent-tool`).
2. On your own machine (or wherever you have `git` and can enter your
   GitHub credentials — not here, for security), download the
   `webapp` folder from this chat, then:
   ```bash
   cd webapp
   git init
   git add .
   git commit -m "Content agent dashboard tool"
   git branch -M main
   git remote add origin https://github.com/YOUR-USERNAME/content-agent-tool.git
   git push -u origin main
   ```

## 2. Import into Vercel

1. Go to [vercel.com/new](https://vercel.com/new) and sign in (free account
   is fine).
2. Click **Import** next to the GitHub repo you just pushed.
3. Framework preset should auto-detect as **Next.js** — leave defaults.
4. **Before clicking Deploy**, add the two environment variables (next
   section) — or add them after and redeploy.

## 3. Set environment variables

In the Vercel project → **Settings → Environment Variables**, add:

| Name | Value |
|---|---|
| `APIFY_API_TOKEN` | Your Apify API token (apify.com → Settings → Integrations) |
| `TOOL_PASSWORD` | Any password you choose — this gates the whole tool |

Apply both to **Production** (and Preview/Development if you want to test
branch deploys too). Save, then trigger a deploy (or redeploy if you
already deployed once) so the new variables take effect.

## 4. Use it

Open the `https://your-project.vercel.app` link Vercel gives you, log in
with your `TOOL_PASSWORD`, fill in the form, and click **Generate
Dashboard**. It'll take 1–3 minutes while Apify actually scrapes the
profiles — the page polls automatically and shows the finished dashboard
when ready, with **Download HTML** and **Open in new tab** buttons.

## What this tool does NOT do

- **No AI reasoning.** Per your choice, the Ideator/Hook & Script content
  is rule-based (keyword/pattern matching on captions), not generated by
  a language model. It only surfaces a pattern (POV hooks, occasion
  tie-ins, creator collabs, storytelling captions, partnerships) if real
  evidence for it was found in the actual pulled data — it won't invent
  ideas that aren't there. Expect lower judgment/nuance than a human (or
  an LLM) reading the captions directly.
- **No holiday lookup.** It doesn't know your local public holidays.
  Use the "dates to treat as respectful/no-hard-sell" field to add any
  yourself.
- **No DM handling.** Same as the original dashboard — Instagram DMs need
  Meta's official Business API, out of scope here.
- **Costs real Apify usage** every time you run it — each generation
  triggers a real scrape. Keep the results limit reasonable (30-50) to
  stay within your Apify plan's usage.

## Updating it later

The whole tool is normal, editable code — nothing here is generated
magic. `lib/ideator.js` has the 5 pattern-detection rules if you want to
tune or add to them; `lib/calendar.js` has the evergreen filler post
templates; `lib/renderDashboard.js` is the dashboard's HTML/CSS/JS.
Push changes to GitHub and Vercel redeploys automatically.
